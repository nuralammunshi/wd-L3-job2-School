# wd-L3-job2-School

Responsive seven-page school website built with Bootstrap 5.

## Pages

- `index.html` — Home
- `about.html` — School history, leadership, mission, and vision
- `teacher.html` — Teachers by subject
- `student.html` — Student achievements and feedback
- `result.html` — Sample result search and previous-year highlights
- `academic.html` — Departments and academic calendar
- `login.html` — Demo sign-in form

## Run locally

Open `index.html` in a browser. Bootstrap and Bootstrap Icons are loaded from a CDN, so an internet connection is needed for those assets.

The login and result search use demonstration data only and are not connected to a school backend.
